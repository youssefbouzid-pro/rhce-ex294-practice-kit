Exam instructions

  1. Read each task carefully before making changes.
  2. Complete the requested configuration on the managed nodes.
  3. Verify configurations before moving on.
  4. Manage time effectively; the countdown continues while you navigate between tasks.
  5. Run the validation script after completing the exam.
Practice setup (not for exam): create the research volume group on each managed node before attempting Task 17. The task itself only creates the data logical volume.
